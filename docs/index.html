trackme · docs

Una API diminuta para aprender GitHub Actions de punta a punta.

Qué es trackme

trackme es una app Node/Express de juguete: lo bastante pequeña para leérla entera en cinco minutos y lo bastante real para montar sobre ella un pipeline completo de CI/CD (lint, tests, matriz, imagen Docker, Pages, releases y seguridad).

Endpoints

RutaDevuelve
GET /health{ "status": "ok" }
GET /api/sum?a=2&b=2{ "result": 4 }
/Un dashboard mínimo que consume /api/sum

Arranque en local

npm ci → npm run dev → http://localhost:8080. Opción contenedor: docker build -t trackme . y docker run --rm -p 8080:8080 trackme.

Cómo se despliega

Esta página vive en docs/ y la publica GitHub Actions desde la rama main (sección 5 del taller: job web con upload-pages-artifact + deploy-pages). La API, además, se empaqueta como imagen en ghcr.io desde el mismo workflow.

Página estática sin build: la publica tal cual GitHub Pages.
